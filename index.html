shorts-uploader — Privacy Policy

Last updated: 17 November 2026

shorts-uploader is a private, non-public tool run by a single independent creator on their own computer. It uploads, schedules and checks videos on the creator's own YouTube channel (กลไกรอบตัว) using the YouTube API Services. It has no other users and is not offered to the public.

What data the tool accesses

  • Through the YouTube Data API, with the channel owner's own OAuth consent: the owner's channel id and the owner's own videos (titles, descriptions, privacy status and scheduled publish time), only to upload, schedule, verify and manage those videos.
  • The tool does not access, collect or store data about any other YouTube user, viewer, commenter or subscriber.

How data is stored and shared

  • OAuth tokens and video records are stored only on the owner's computer, in files readable only by the owner. They are never sold, shared, or sent to any third party, and are not used for advertising.
  • No analytics, cookies or tracking are used by this tool.

Revoking access

The channel owner can revoke the tool's access at any time at Google Account → Third-party access. Deleting the local token files removes all stored credentials.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
